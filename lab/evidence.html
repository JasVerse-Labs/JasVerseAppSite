Case study: BBP Cross-Platform Build Portability

Problem: a filename/import case mismatch worked fine in the usual development environment, but failed on a different operating system.

Finding: a clean-room test — building the project from a fresh checkout, with no leftover local state — surfaced the failure immediately, where normal day-to-day development never would have.

Action: the specific mismatch was fixed, and an automated check was added so the same class of problem can't silently return.

Result: a portable, clean build — verified, not just assumed.
